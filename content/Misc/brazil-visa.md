我有幸 [中稿 ICLR 2026](https://openreview.net/forum?id=nrBJ0Uvj7c)， 即将赴巴西参会。本文结合我自己的实际申请经验，梳理了巴西签证申请的详细流程与所需材料，供有类似需求的同学参考。

## 申请流程

### 1. 注册会议，获取会议邀请函

中稿并注册会议后，可于*会议官网 -- My Stuff -- Registration History*处下载**会议邀请函**。邀请函是用于学校出国审批和签证申请的重要文件！

![[brazil-visa-invitation-letter.png]]

### 2. 学校审批

不少学校对学生因公出国有着严格的审查机制。以北京大学为例，需在*校内门户 -- 提交出国（境）审批申请*系统内提供详细信息，并附上**会议邀请函**、**导师知情同意书**和**家长知情同意书**；关于出境入境日期限制及其他细则，请参考 [学校官方说明](https://www.oir.pku.edu.cn/info/1044/1161.htm)。建议提前至少一个半月准备并提交材料。通常学校的审批速度较快，可在 3 个工作日内完成。

学校审批通过后，会收到**出国任务通知书**。该通知书将作为报销的重要依据，但并不能作为签证申请的核心依据。学生还需自行打印用于签证申请的以下关键材料：

* **单位同意书**（含费用证明，英语）
* **学校的法人证明**（英语）
* **在读证明**（英语或中英双语）

北京大学学生可在自助智能打印机上凭校园卡直接打印上述材料。

### 3. 填写签证申请表

进入 [巴西领事服务官网](https://formulario-mre.serpro.gov.br/)，选择*Foreign Citizen -- VISA -- Start New Application*，完整且正确地填写**签证申请表**。个人信息需与护照信息页一致。记得仔细阅读并遵守填写要求和证件照要求！

在签证申请表的最后一页，需上传证件照，电子签名，以及其他**证明材料**。[材料清单](#材料清单) 章节将给出证明材料清单。

填写完成后，点击*Print Delivery Receipt*，将**签证申请收据**下载下来。签证申请收据上，有**签证申请恢复码 (Application Recovery Code，也叫 Retrieval Code)** 和 **签证申请编号 (Application Code)**。幸运的是，我们在后续任意时刻都可以凭恢复码来重新登入申请表填写界面，修改信息和证明材料；修改过后，恢复码和申请编号并不会改变。因此，为了节省时间，建议先粗略填写申请表并提交，以获得恢复码和申请编号，从而进行后续预约步骤；在等待材料递交期间，再逐步完善信息和证明材料（如机票，酒店等）。

### 4. 预约材料递交

登陆 VFS 官网，选择 [中国-巴西](https://visa.vfsglobal.com/chn/zh/bra)，按指示逐步完成线下材料递交的预约；需支付预约费用 27.8 元。签证类型选择**访客签证 - 其他**；千万不要选择商务签证！预约完成后，邮箱将收到**预约信**。

### 5. 递交材料

在预约好的时间前往签证申请中心递交材料；迟到太久预约号将作废，故建议提前 15 分钟左右到达。确保 [材料清单](#材料清单) 中的所有材料都已准备就绪。

递交材料时，需支付服务费和签证费，共计约 700 元。

递交材料结束后，可以自行选择护照递送方式：现场取或 EMS 邮寄。EMS 邮寄需支付额外邮费。

### 6. 等待审核

进入 [巴西领事服务官网](https://formulario-mre.serpro.gov.br/sci/pages/web/ui/#/consultar-situacao)，选择*Check Status*，使用恢复码查询签证办理进度。

![[brazil-visa-status.png]]

签证办理完成后，前往线下取回护照，或收取 EMS 邮寄的护照。

## 材料清单

以下内容必须线下递交纸质版本，但不需要上传至签证申请表：

- [ ] 签证申请收据
- [ ] 签证预约信
- [ ] checklist（前往 [VFS官网](https://visa.vfsglobal.com/one-pager/brazil/china/english/)，选择签证类型*Study, internship, research, seminars or scientific cooperation*，在*Documents Required*里下载 checklist）

以下材料需要上传至签证申请表，并线下递交纸质版本：

* [ ] 会议邀请函
* [ ] 护照原件
* [ ] 英文版往返机票行程单（最好是已经购买完成的机票；记得**购买可以全额退款的机票**）
* [ ] 材料递交前 7 天内生成的 3 个月内银行流水单（语言不限；可用 app 办理，参考 [这个帖子](https://www.xiaohongshu.com/discovery/item/67edf376000000001b02580b?source=webshare&xhsshare=pc_web&xsec_token=CBm6sh1apxTSec2CISLxlxgFZCp1Op2Hhqf2QrMSyphSc=&xsec_source=pc_share)）
* [ ] 一张 4cm $\times$ 5cm 的白底证件照（尺寸要求因目标国家而异！）

以下是其他可选的证明材料。上传至签证申请表，并线下递交纸质版：

* [ ] 护照复印件
* [ ] 身份证复印件
* [ ] 学生证或校园卡复印件
* [ ] 英文版酒店预订单（酒店通常都可以取消并全额退款；参考 [这个帖子](https://www.xiaohongshu.com/discovery/item/674d2ee60000000007031f22?source=webshare&xhsshare=pc_web&xsec_token=CB3lMgkvehPDEgChDyem1P5Gma6natzx0NDdX1Y6d2qIU=&xsec_source=pc_share)）
* [ ] 论文接收界面截图（推荐），论文原文（太长了，不推荐）
* [ ] 会议注册收据
* [ ] 家长知情同意书，导师知情同意书
* [ ] 学校开具的任务通知
* [ ] 学校开具的单位同意书（含费用证明）
* [ ] 在读证明
* [ ] 学校法人证明

## 其他注意事项

* VFS 官网时常出现问题。记得登录时关闭一切网络代理。另外，可以考虑用多个邮箱注册多个账号。
* 线下材料递交排队过程非常折磨😫，需等待 3 小时以上。可以考虑花钱升级为 VFS 的 VIP，直接插队快速办理。
* 银行流水需体现充足资金，建议余额高于预期花费。
* 扫描纸质文件，推荐直接使用 IOS 自带的 [Notes](https://support.apple.com/zh-cn/108963)。简单好用无水印。
